# 橡皮艇漂流

一个在浏览器里玩的俯视角漂流小游戏：划着橡皮艇顺流而下，沿着星星走，避开礁石与漂木。目前有两关，通关上一关后解锁下一关：

- **第一关 · 青溪谷**：林间溪流，学习转向、冲刺，躲礁石和漂木。
- **第二关 · 鹰嘴峡**：峡谷更窄、水更急，新增会把艇吸进去的漩涡，和只留一个缺口的石门。

直接用浏览器打开 `index.html` 即可，无需构建，也没有任何依赖。

## 操作

| | 键盘 | 触屏 / 鼠标 |
|---|---|---|
| 转向 | `←` `→`（或 `A` `D`） | 按住屏幕左侧 / 右侧 |
| 前进 | `↑`，或同时按 `←` `→` | 两侧同时按住 |
| 冲刺（消耗体力） | `空格` 或 `Shift` | 底部中间按钮 |
| 倒划减速 | `↓` | — |
| 暂停 / 静音 / 重开 | `P` / `M` / `R` | 左上角按钮 |

## 规则

- 橡皮艇有 3 格气囊，撞到礁石或漂木扣一格，蹭河岸只会减速。
- 救生圈可以补一格气囊，满气时改为加分。
- 漩涡越靠近中心吸力越大，卷到中心会扣一格气囊；提前绕开，或冲刺甩脱。
- 三颗星：抵达终点、收集 80% 以上的星星、全程零碰撞。

## 设置

主菜单和暂停界面里都有「设置」：音量、转向灵敏度、画质（手机卡顿时选「流畅」）、撞击震动，以及重置进度。设置和进度都保存在浏览器本地。
