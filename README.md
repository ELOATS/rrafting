# 橡皮艇漂流

一个在浏览器里玩的俯视角漂流小游戏，画成一幅会动的水彩画：划着橡皮艇顺流而下，沿着莲花走，避开礁石与漂木。目前有三关，通关上一关后解锁下一关：

- **第一关 · 青溪谷**：春天的早晨，桃花和新柳。学习转向、冲刺，躲礁石和漂木。
- **第二关 · 鹰嘴峡**：雾里的峡谷，青灰的岩壁和苍松。河道更窄、水更急，新增会把艇吸进去的漩涡，和只留一个缺口的石门。
- **第三关 · 落霞滩**：秋天的傍晚，红枫和映着晚霞的水。新增一级级的跌水——要对准中间光滑的 V 形水舌冲下去，两侧的白水是会把艇卷住的回流。

游戏本体是一个 `index.html`，无需构建，没有运行时依赖。直接用浏览器打开就能玩。

## 画风

画面全部由代码即时画出，没有任何图片素材，按水彩的路子来：

- 颜色是薄薄地罩在纸上的，边缘晕开，深浅靠一层层叠色；纸纹和颜料的颗粒压在最上面。
- 影子用冷紫灰而不是黑色；轮廓用断续的墨线勾。
- 水面的高光是留白：顺流的笔触、急流里的干笔飞白、跌水下成片的白。
- 三关各有一套季节的颜色，树也不同：桃花、梨花和柳，苍松，红枫和金叶。
- 界面尽量轻：纸卡、楷体标题、几枚小纸钮，评价用莲花表示。

## 规则

- 橡皮艇有 3 格气囊，撞到礁石或漂木扣一格，蹭河岸只会减速。
- 救生圈可以补一格气囊，满气时改为加分。
- 漂木顺着水流往下漂，会被礁石和河岸挡开。轻轻蹭到只是把它推开，高速撞上去才会扣气囊；从旁边绕过去超车。
- 漩涡越靠近中心吸力越大，卷到中心会扣一格气囊；提前绕开，或冲刺甩脱。
- 跌水两侧的回流会把艇按在落差下面：速度够快能冲过去，被卷住就全力划出来，困太久会扣一格气囊。
- 评价最多三朵莲花：抵达终点、采到 80% 以上的莲花、全程零碰撞。

## 设置

主菜单和暂停界面里都有「设置」：音量、转向灵敏度、画质、背景音乐、撞击震动、全屏，以及重置进度。画面持续卡顿时会自动降到「流畅」画质。设置和进度都保存在浏览器本地。

## 部署

这是一个纯静态站点，把仓库内容原样放到任何静态托管上即可。用 GitHub Pages 的话：

1. 仓库 **Settings → Pages**。
2. **Source** 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
3. 一两分钟后访问 `https://<用户名>.github.io/rrafting/`。

通过 https 访问时会自动注册离线缓存（`sw.js`）：有网时总是取最新版本，断网时用上次缓存的版本。手机浏览器里可以"添加到主屏幕"，之后像应用一样全屏启动。

## 开发与测试

```
npm install                      # 只为测试安装 Playwright
npx playwright install chromium
npm test                         # 跑冒烟测试
npm start                        # 本地起一个静态服务器 http://localhost:8080
```

`tests/smoke.js` 会用无头浏览器加载游戏并检查：

- 每一关的生成结果满足硬性约束（礁石与河岸之间不留会夹住艇的窄缝、莲花不贴着障碍等）；
- 机器人能稳定通关，且零碰撞的满评价可以达成；后两关不操作无法通关；
- 物理是确定性的：同样的操作得到同样的结果；
- 随机乱按 45 局不会出现数值异常、艇出河道或卡死；
- 开始、暂停、设置、存档、解锁这条界面流程；
- 没有 `roundRect` 的旧浏览器、320×568 的小屏手机、断网离线。

推送到 `main` 时 GitHub Actions 会自动跑这套测试（`.github/workflows/test.yml`）。

## 浏览器支持

面向近几年的 Chrome、Edge、Firefox、Safari（含 iOS Safari）。自动化测试只在 Chromium 上跑；对其他浏览器只做了兼容性处理（如 `roundRect` 补丁、不依赖较新的 CSS 和音频接口写法），没有逐一实机验证。

## 隐私

游戏不联网、不收集任何数据。进度和设置只保存在你自己浏览器的本地存储里。
