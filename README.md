# 橡皮艇漂流

一个在浏览器里玩的俯视角漂流小游戏：划着橡皮艇顺流而下，沿着星星走，避开礁石与漂木。目前只有第一关「青溪谷」。

直接用浏览器打开 `index.html` 即可，无需构建，也没有任何依赖。

## 操作

| | 键盘 | 触屏 / 鼠标 |
|---|---|---|
| 转向 | `←` `→`（或 `A` `D`） | 按住屏幕左侧 / 右侧 |
| 全力前进 | `↑`，或同时按 `←` `→` | 两侧同时按住 |
| 倒划减速 | `↓` | — |
| 暂停 / 静音 / 重开 | `P` / `M` / `R` | 左上角按钮 |

## 规则

- 橡皮艇有 3 格气囊，撞到礁石或漂木扣一格，蹭河岸只会减速。
- 救生圈可以补一格气囊，满气时改为加分。
- 三颗星：抵达终点、收集 80% 以上的星星、全程零碰撞。
